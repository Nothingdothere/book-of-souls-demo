# Книга душ — демоверсия

Рисованная 2D-игра на Godot о Жнеце Дарке, которому предстоит слушать человеческие души и решать их судьбу.

## Управление

- `A` / `D` или стрелки — движение
- `E` — разговор
- `J` — книга душ
- мышь, `Space` или `Enter` — управление диалогом
- `Esc` — закрыть диалог или книгу

После решения судьбы Лины вернитесь к Касу. Его следующий разговор откроет кнопку перехода в кофейню «Точка». Из кофейни можно выйти налево на улицу и вернуться через дверь или кнопкой в зал распределения.

## Редактирование локаций в Godot

Откройте в панели «Файловая система» сцену `scenes/coffee.tscn`, чтобы вручную двигать стены, пол, стойку, передний план и кошку. Для улицы откройте `scenes/street.tscn`. Эти сцены используются игрой напрямую: после сохранения изменения появятся при следующем запуске. `scenes/main.tscn` показывает зал с Касом.

В кофейне узел `CoffeeSpawn`, а на улице `PlayerSpawn` задают место появления Дарка. Внутри каждого находится `DarkPreview`: меняйте его `Scale` по обеим осям одинаково, чтобы настроить размер Дарка в этой локации, и `Position`, чтобы совместить его ноги с полом. Макеты видны только в редакторе; при запуске игра показывает настоящего персонажа с теми же настройками. Дома, расставленные вручную в `street.tscn`, остаются на местах; при движении влево игра достраивает улицу с разными промежутками между домами. Продолжение видно при запуске игры.

Общий масштаб локации задаётся свойством `Gameplay Zoom` на корневом узле `Coffee` или `Street`: меньшее значение показывает больше пространства. При запуске отдельной сцены клавишей F6 используется такой же обзор, как в основной игре, и виден макет Дарка. В основной игре вместо макета работает анимированный персонаж.


На телефоне используются экранные кнопки. Для удобной игры поверните устройство горизонтально.
