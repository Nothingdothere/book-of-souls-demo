# Книга душ — демоверсия

2D-игра на Godot о Жнеце, которому предстоит слушать человеческие души и решать их судьбу.

Играть в браузере: https://nothingdothere.github.io/book-of-souls-demo/

Проект находится в стадии прототипа.

Для обновления GitHub Pages экспортируйте пресет `Web` в `docs/index.html`, затем выполните `python tools/compact_web_pack.py docs/index.pck`. Утилита хранит одинаковые кадры анимации в пакете один раз, сохраняя все пути и содержимое ресурсов, и обновляет размер пакета в HTML. Это позволяет уложиться в ограничение GitHub без изменения качества рисунков или музыки.
